UX vs UI

Apresentação sobre a diferença entre User Experience (UX) e User Interface (UI).

Apresentadores: Leonardo e Vitor

Conceito 1

O que é UX?

UX = User Experience (Experiência do Usuário)

  • É a experiência completa do usuário com um produto digital.
  • Envolve pesquisa, testes, jornada e arquitetura da informação.
  • Responde: "o produto resolve o problema de forma eficiente?"
  • Exemplo: o caminho até concluir uma compra num app.
Analogia: UX é como o layout de uma loja — corredores organizados, sinalização clara, caixa fácil de achar.

Conceito 2

O que é UI?

UI = User Interface (Interface do Usuário)

  • É a camada visual e interativa do produto.
  • Cores, tipografia, botões, ícones, espaçamento, animações.
  • Responde: "o produto é visualmente atraente e coerente?"
  • Exemplo: o design da tela, botão de compra, cores da marca.
Analogia: UI é a decoração da loja — iluminação, paleta de cores, móveis, visual das prateleiras.

Exemplos práticos

Como aparece no mundo real

UX Ruim

App bonito mas confuso. Usuário se perde no checkout e desiste.

UI Ruim

Fluxo bom, mas visual feio. Passa desconfiança.

UX + UI Bom

Fácil de usar e bonito. Usuário ama o produto.

Resumindo: UX é a planta da casa, UI é a decoração. Precisa dos dois.
